# Give Me The Grind

> A browser-only calendar generator for the relentlessly employable.

Give Me The Grind turns a normal workday into a high-performance narrative before your first coffee gets cold. Configure your working hours, choose your preferred flavor of corporate nonsense, and generate a calendar full of strategic pauses, inbox theater, founder-mode combustion, and other activities that look excellent in a quarterly retrospective.

The output is a real `.ics` calendar file. The ambition is fictional.

## What It Does

Give Me The Grind lets you:

- Pick a date range of up to 31 calendar days.
- Choose active weekdays and a work window.
- Set minimum and maximum focus-block lengths.
- Schedule strategic breaks and an optional lunch break.
- Select one or more grind styles.
- Dial the intensity from **Gentle nudge** to **Unhinged growth**.
- Enable spicy content when the boardroom-safe catalog is not sufficiently transformational.
- Generate a preview in English or Swedish.
- Download the result as a standard `.ics` calendar file.

Everything runs in the browser. No account, backend, or quiet lead-generation funnel is required.

## The Corporate Satire Engine

The generator is powered by a catalog of fictional calendar events inspired by the language of LinkedIn posts, startup decks, productivity influencers, and meetings that should have been emails.

| Grind style | Strategic translation |
| --- | --- |
| **Networking** | Turn a coffee chat into relationship capital and a possible warm introduction. |
| **Pivoting** | Change direction, rename the obstacle an opportunity, and backdate the conviction. |
| **Thought leadership** | Publish a familiar observation as a vulnerable framework with a branded name. |
| **Productivity theater** | Build a system to measure the system that proves you are building systems. |
| **Inbox theater** | Add the right people to a thread and call the resulting anxiety visibility. |
| **KPI & alignment** | Give a number a North Star, a moonshot, and a quarterly off-site. |

At higher intensity levels, the vocabulary becomes increasingly confident while the measurable output remains delightfully negotiable.

## Privacy, Or At Least The Good Kind Of Privacy

The app is local-first by design:

- Settings are not saved between refreshes.
- Nothing is uploaded to a server.
- Calendar files are generated and downloaded directly in your browser.
- The app does not need your email, employer, manager, or five-year plan.

## Run It Locally

Requirements: Node.js and npm.

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

Useful commands:

```bash
npm test       # Run the test suite
npm run lint   # Type-check the app
npm run build  # Type-check and create a production build
```
